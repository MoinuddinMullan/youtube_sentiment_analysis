The problem was **three compounding failures** at once:

#### ❌ Problem 1 — Training data had garbage labels
VADER alone labeled `"Don't bother watching, code is outdated"` as **neutral** (because it doesn't know "don't bother" is dismissive), and `"Oh great, another tool that breaks"` as **positive** (it saw "great"). So the model learned from wrong examples.

#### ✅ Fix — Rule-corrected labeling layer
I added **18 strong negative regex patterns** that run BEFORE VADER during training. Phrases like "don't bother", "clickbait", "painful to watch", "unsubscribed", "lost all respect" — are now **always labeled negative**, no matter what VADER says.

#### ❌ Problem 2 — Preprocessing destroyed sarcasm signals
`"Oh great... 🙄"` → emoji stripped → `"oh great"` → looks positive to the model. Ellipsis (`...`) stripped → sarcasm signal gone. `"don't like"` → "dont like" → model sees "like" as a positive word.

#### ✅ Fix — Smart preprocessing
- 🙄 → `"eye_roll_emoji"`, 💀 → `"skull_emoji_lol"`, 🔥 → `"fire_great_emoji"`
- `"don't like"` → `"dont NOT_like"` (negation prefixing for 4 words after every negation)
- `"..."` → `"ellipsis_sarcasm"` token
- `"Oh great"` → `"sarcasm_oh_great"` token

#### ❌ Problem 3 — Model algorithm was too weak
Logistic Regression with bigrams couldn't distinguish subtle patterns. 

#### ✅ Fix — LinearSVC + trigrams + 50k features
LinearSVC is the gold standard for text classification. Trigrams now catch 3-word phrases like `"painful to watch"`, `"don't bother watching"` as single features. Vocabulary doubled from 20k to 50k features.
